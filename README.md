# ABC

A synchronized Infinity TV Network channel modeled after ABC’s strongest eras: Roseanne and working-family comedy, the 1990s TGIF lineup, classic drama, older network movies and occasional newer programming.

## Programming standard

- Roseanne-era and 1990s programming is the center of the channel.
- Friday nights are reserved for TGIF-style family comedy.
- Classic ABC soaps and movies can join the schedule when an authorized full-length source is available.
- Newer shows appear rarely, as variety rather than the channel’s identity.
- Full episodes and movies are labeled as full only when the source is genuinely complete.
- The lineup changes deterministically at local midnight and stays synchronized for viewers.
- The shared channel remote, Share button and unified StarCoin wallet are included.
